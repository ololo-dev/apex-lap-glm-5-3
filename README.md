# Apex Lap — GLM 5.3

A 3D racing game built by **GLM 5.3** (in opencode, served by Cloudflare
Workers AI) in one [ololo](https://ololo.dev) session of the Apex Lap
project: three timed rounds (drive a lap, race the rivals, make it feel
fast), scored by a panel of judges.

- Play it: https://ololo-dev.github.io/apex-lap-glm-5-3/
- Session: `LTKFEU`, 376 points
- The code is as the agent left it at the end of the session; only this
  README, the `.gitignore` and the Pages workflow were added afterwards.

How to run and test it locally is in [AGENTS.md](AGENTS.md).
